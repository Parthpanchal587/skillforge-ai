🚀 SkillForge AI

AI-powered learning & career platform for engineering students.

SkillForge AI helps students learn, practice, track progress, and prepare for careers using AI-powered tools.

✨ Features

- 🤖 AI Mentor with Ollama
- 📚 Course & Learning Library
- 📊 Personalized Dashboard
- 🔐 JWT Authentication
- 📈 Progress Tracking
- 💼 Career & Interview Tools
- ⚡ Modern Responsive UI

🛠️ Tech Stack

Frontend: React, Vite, Tailwind CSS, Zustand
Backend: Node.js, Express.js, SQLite, JWT
AI: Ollama
Deployment: Vercel

🌐 Live Demo

👉 https://skillforge-ai-kohl.vercel.app

⚙️ Run Locally

git clone https://github.com/Parthpanchal587/skillforge-ai.git
cd skillforge-ai
npm install

Start the frontend and backend according to their respective package scripts.
